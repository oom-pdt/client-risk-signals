# Client Risk Signals prototype

A clickable prototype of the Health & risk view on a client record in OOm's Agency CRM: client and service health, email sentiment over time, response speed, and risk signals grouped by category.

- **Fictional data only.** Every client, contact, email, invoice and date is made up. Nothing here reads real email.
- **Prototype, not production code.** It is a single static HTML file (`index.html`) with no build step and no dependencies.
- Sections outside risk signals are shown blurred or disabled on purpose.

Open `index.html` in a browser, or see the GitHub Pages link in the repository description.
